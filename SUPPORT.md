# Support

- For a reproducible defect, use the affected repository's bug form.
- For a proposed capability, use its feature-request form.
- For setup or operational help, first check that repository's README and docs.
- For security-sensitive matters, follow the private process in `SECURITY.md`.

Do not include credentials, private keys, production data, or confidential logs
in issues. This organization-default repository does not provide product support
on behalf of individual repositories.
