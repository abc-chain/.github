# Security policy

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, customer data, or exploit details
in a public issue or discussion.

Use the repository's **Report a vulnerability** link when private vulnerability
reporting is available. Otherwise, contact an `abc-chain` organization owner
through the established private company communication channel and include:

- the affected repository and version or commit;
- impact and reproduction conditions;
- a minimal proof of concept without real customer data;
- any known mitigation.

If a credential may have been exposed, revoke or rotate it immediately; removing
it from Git history is not sufficient.

## Supported versions

Each product repository documents its supported versions. Security fixes are
normally applied to actively supported branches only.
